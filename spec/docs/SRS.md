# Software Requirements Specification (SRS)
# Nature on Zoom — Bird Nest Streaming Stub Site

**Версия:** 1.0.0  
**Дата:** 2025-12-28  
**Статус:** Draft

---

## 1. Введение

### 1.1 Назначение документа
Данный документ описывает функциональные и нефункциональные требования к сайту-заглушке "Nature on Zoom", который должен выглядеть как легитимный стриминговый сервис для наблюдения за птичьими гнёздами.

### 1.2 Область применения
Сайт предназначен для:
- Маскировки VPN-трафика под легитимный веб-сервис
- Обхода DPI-анализа
- Создания правдоподобной "обложки" для сетевых анализаторов

### 1.3 Определения и сокращения

| Термин | Определение |
|--------|-------------|
| DPI | Deep Packet Inspection — глубокий анализ сетевых пакетов |
| OAuth | Open Authorization — протокол авторизации |
| WebSocket | Протокол двусторонней связи поверх TCP |
| Heartbeat | Периодические сигналы для поддержания соединения |
| Stub | Заглушка — имитация функционала без реальной реализации |

## 2. Общее описание

### 2.1 Перспектива продукта
Nature on Zoom — это frontend-приложение с минимальным backend-компонентом (WebSocket-сервер), имитирующее стриминговый сервис для наблюдения за дикой природой.

### 2.2 Функции продукта (высокий уровень)
1. Отображение 8 видео-фреймов птичьих гнёзд
2. Имитация OAuth-аутентификации через Google
3. Имитация формы оплаты
4. WebSocket heartbeat для имитации live-трафика
5. Стильное меню с SVG-анимациями

### 2.3 Классы пользователей

| Класс | Описание |
|-------|----------|
| Посетитель | Обычный пользователь сайта (или DPI-система) |
| Краулер | Поисковый робот, анализирующий структуру сайта |
| DPI-анализатор | Система инспекции трафика |

### 2.4 Ограничения
- Нет реального видеоконтента
- Нет реальной обработки платежей
- OAuth — имитация (в MVP)

### 2.5 Зависимости
- Cloudflare (SSL/TLS)
- VPS ALma Linux (хостинг)
- Веб-браузер с поддержкой ES6+, WebSocket

## 4. Нефункциональные требования

### 4.1 Дизайн (NFR-01)
| Параметр | Требование |
|----------|------------|
| Цветовая схема | Пастельные/природные цвета |
| Углы | Скруглённые (border-radius: 12-20px) |
| Анимации | Плавные (transition: 0.3s ease) |
| Иконки | SVG с анимациями |
| Шрифты | Google Fonts (рекомендуется: Inter, Outfit) |

### 4.2 Правдоподобность для DPI (NFR-02)
| Параметр | Требование |
|----------|------------|
| TLS | 1.3 (обеспечивает Cloudflare) |
| HTTP | HTTP/2 |
| WebSocket | Активные heartbeat-соединения |
| API | Реалистичные endpoints с JSON-ответами |
| HTML | Семантическая разметка, meta-теги |

### 4.3 Производительность (NFR-03)
| Параметр | Требование |
|----------|------------|
| First Contentful Paint | < 2 сек |
| Размер страницы | < 500 KB (без изображений) |
| WebSocket latency | < 100 ms |

### 4.4 Совместимость (NFR-04)
| Браузер | Минимальная версия |
|---------|-------------------|
| Chrome | 90+ |
| Firefox | 90+ |
| Safari | 14+ |
| Edge | 90+ |

### 4.5 Безопасность (NFR-05)
| Параметр | Требование |
|----------|------------|
| HTTPS | Обязательно (Cloudflare) |
| CSP | Content-Security-Policy header |
| XSS | Нет пользовательского ввода в DOM |
