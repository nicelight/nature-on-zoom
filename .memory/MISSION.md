# MISSION — Nature on Zoom

## Назначение проекта
**Nature on Zoom** — сайт-заглушка, маскирующийся под легитимный стриминговый сервис наблюдения за дикой природой (webcam птичьих гнёзд).

## Ценность
- Обеспечить правдоподобный веб-трафик для обхода DPI-анализа
- Выглядеть как настоящий стриминговый сервис для краулеров и анализаторов
- Не вызывать подозрений у систем обнаружения VPN-туннелей

## Scope (границы проекта)

### В scope:
- Статический frontend с 8 видео-фреймами птичьих гнёзд
- Имитация OAuth Google (позднее — реальный OAuth)
- Имитация формы оплаты
- Минимальный WebSocket-бэкенд для имитации стримингового трафика
- Пастельный дизайн с плавными анимациями
- SVG-иконки и анимированные элементы

### Вне scope:
- Реальный видеоконтент
- Реальная обработка платежей (TODO)
- Метрики/аналитика
- Юридические документы
- SEO-оптимизация (robots.txt, sitemap)

## Целевая аудитория
- Worldwide (английский язык)
- Системы DPI и сетевые анализаторы (должны видеть "легитимный" сервис)

## Технический стек
- Frontend: HTML5, CSS3, Vanilla JavaScript
- Backend: Минимальный WebSocket-сервер (Python/Node.js)
- Хостинг: VPS ALma Linux
- SSL: Cloudflare (уже настроен)
