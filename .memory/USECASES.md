# USECASES — Сценарии использования

## UC-01: Просмотр главной страницы

**Актор:** Посетитель сайта / DPI-анализатор

**Предусловия:** Пользователь открыл сайт

**Основной сценарий:**
1. Пользователь видит шапку с логотипом "Nature on Zoom"
2. Пользователь видит меню: Watch, Charge, Check
3. Пользователь видит 8 видео-фреймов с превью гнёзд
4. Каждый фрейм содержит: заголовок, превью, описание, цену
5. WebSocket-соединение устанавливается автоматически (heartbeat)

**Acceptance Criteria:**
- [ ] Логотип отображается в шапке
- [ ] Меню содержит 3 пункта с SVG-иконками
- [ ] 8 фреймов расположены вертикально
- [ ] Каждый фрейм имеет кнопку Play
- [ ] WebSocket-соединение активно

---

## UC-02: Попытка просмотра контента

**Актор:** Посетитель сайта

**Предусловия:** Пользователь на главной странице

**Основной сценарий:**
1. Пользователь нажимает кнопку "Play" на любом фрейме
2. Открывается модальное окно OAuth Google
3. Пользователь видит имитацию формы входа Google
4. Пользователь "входит" (любые данные или кнопка)
5. Открывается страница оплаты (Charge)

**Acceptance Criteria:**
- [ ] Клик на Play открывает модальное окно
- [ ] Модальное окно выглядит как Google OAuth
- [ ] После "входа" редирект на /charge.html
- [ ] Сохраняется ID выбранного фрейма

---

## UC-03: Оплата контента

**Актор:** "Авторизованный" посетитель

**Предусловия:** Пользователь прошёл OAuth

**Основной сценарий:**
1. Пользователь видит форму оплаты
2. Форма показывает сумму $5
3. Пользователь вводит данные карты (имитация)
4. Пользователь нажимает "Pay"
5. Редирект на главную страницу

**Acceptance Criteria:**
- [ ] Форма отображает сумму $5
- [ ] Поля: номер карты, срок, CVV
- [ ] Кнопка Pay активна
- [ ] После клика → редирект на index.html
- [ ] Никаких реальных транзакций

## UC-05: Heartbeat для DPI

**Актор:** DPI-анализатор / Сетевой анализ

**Предусловия:** Страница загружена

**Основной сценарий:**
1. При загрузке страницы JS открывает WebSocket
2. Каждые 30 секунд отправляется ping
3. Сервер отвечает pong
4. При наведении на фрейм — fetch-запрос метаданных

**Acceptance Criteria:**
- [ ] WebSocket-соединение на /ws/heartbeat
- [ ] Ping каждые 30 сек
- [ ] Запрос /api/stream/preview/{id} при hover
- [ ] Трафик выглядит как стриминговый сервис
